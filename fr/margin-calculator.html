Calculateur de Marge et Prix de Vente

Fixer un prix de vente sans connaître sa marge est le moyen le plus rapide de travailler à perte. Ce calculateur vous donne, à partir de votre coût, le prix de vente pour une marge souhaitée, ou à l’inverse la marge réelle d’un prix existant. Il distingue le taux de marque (profit divisé par le prix de vente) et la majoration (profit divisé par le coût), deux notions souvent confondues. Le calcul se fait dans votre navigateur.

Comment l’utiliser

  1. Choisissez : trouver un prix de vente, ou calculer la marge d’un prix.
  2. Saisissez le coût d’achat hors taxe et la marge voulue (ou le prix).
  3. Indiquez si la marge se calcule sur le prix de vente ou sur le coût.
  4. Lisez le prix, le bénéfice, le taux de marque, la majoration et le coefficient.

Marge ou majoration : ne les confondez pas

Taux de marque = (prix − coût) ÷ prix. Majoration = (prix − coût) ÷ coût. Pour un coût de 100 vendu 150, le bénéfice est 50 : le taux de marque est 33,3 % et la majoration 50 %. Une marge de 50 % sur le prix de vente exige un prix de 200 (coefficient 2), alors qu’une majoration de 50 % donne 150 (coefficient 1,5). Dites toujours sur quelle base vous raisonnez.

Exemples chiffrés

  • Coût 100 MAD, marge souhaitée 40 % sur le prix de vente : prix = 100 ÷ (1 − 0,40) = 166,67 MAD ; bénéfice = 66,67 MAD.
  • Coût 100 MAD, majoration 40 % : prix = 140 MAD ; bénéfice = 40 MAD ; taux de marque = 28,6 %.
  • Coût 80 MAD, prix 120 MAD : bénéfice = 40 MAD ; taux de marque = 33,3 % ; majoration = 50 % ; coefficient = 1,5.

Ce calculateur travaille hors taxe. Pensez à déduire vos autres charges (transport, emballage, commissions, frais fixes) pour obtenir votre vraie rentabilité, puis ajoutez la TVA avec notre calculateur de TVA.

Questions fréquentes

Quelle est la différence entre marge et majoration ?
La marge (taux de marque) se calcule sur le prix de vente ; la majoration se calcule sur le coût. Pour un même bénéfice, la majoration est toujours plus élevée que le taux de marque.

Comment calculer un prix de vente avec une marge de 30 % ?
Divisez le coût par (1 − 0,30), soit par 0,70. Pour un coût de 70, le prix est 100.

Qu’est-ce que le coefficient multiplicateur ?
C’est le prix de vente divisé par le coût. Un coefficient de 1,5 signifie que vous vendez 1,5 fois le coût.

Le prix calculé inclut-il la TVA ?
Non, il est hors taxe. Ajoutez la TVA ensuite avec le calculateur de TVA.
